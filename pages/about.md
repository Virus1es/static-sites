# О проекте

## Cache Research Lab

**Cache Research Lab** — демонстрационный исследовательский сайт,
созданный в рамках практического задания P3
«Воспроизводимый конвейер “данные → результат → сайт”».

Проект демонстрирует автоматизированный процесс обработки
экспериментальных данных и их последующей публикации
в виде статического веб-сайта.

## Цель проекта

Основная цель проекта — продемонстрировать воспроизводимый
конвейер, в котором исходные данные эксперимента автоматически
преобразуются в готовые результаты для публикации.

Основная последовательность работы имеет вид:

**данные → обработка → результаты → публикация**

При изменении исходных данных производные материалы пересчитываются
и сайт обновляется автоматически.

## Основные возможности

### Воспроизводимая обработка

Исходные данные хранятся отдельно от результатов их обработки.
Все производные материалы формируются автоматически
Python-скриптом.

### Кэширование результатов

При отсутствии изменений в исходных данных и коде анализа
повторный расчёт не выполняется.

Это позволяет избежать ненужной повторной обработки
неизменившихся данных.

### Визуализация

Результаты представлены в нескольких формах:

- сводная таблица;
- статические графики;
- интерактивные графики;
- распределение значений экспериментальных показателей.

Интерактивные графики позволяют получать значения показателей
при наведении указателя на соответствующие элементы.

### Научное представление результатов

Страница результатов поддерживает математические выражения
в формате LaTeX, нумерованные формулы, таблицы и рисунки
с подписями.

Это позволяет использовать сайт не только как демонстрацию
pipeline, но и как основу для публикации результатов
исследовательских экспериментов.

### Версионирование

Для результата сохраняются:

- идентификатор текущего Git-коммита;
- версия исходного набора данных;
- дата и время сборки.

Благодаря этому опубликованный результат можно связать
с конкретной версией исходного кода и данных.

## Технологический стек

### Python

Используется для обработки исходных данных,
расчёта показателей и формирования результатов.

### Pandas

Применяется для чтения CSV-файлов,
проверки структуры данных и расчёта агрегированных показателей.

### Matplotlib

Используется для формирования статических графиков.

### Plotly

Используется для создания интерактивных визуализаций
с отображением значений при наведении.

### Nikola

Nikola используется как генератор статического сайта.

В проекте применяется дочерняя тема `cache-lab`,
созданная на основе Bootstrap 4 и визуальной темы Flatly.

### Nox

Nox объединяет отдельные этапы обработки и сборки
в единый воспроизводимый pipeline.

## Архитектура проекта

Исходные данные поступают в Python-скрипт обработки.

После выполнения расчётов формируются таблицы,
статические изображения и интерактивные HTML-графики.

Затем Nikola использует полученные материалы
при сборке статического сайта.

Общая схема имеет следующий вид:

**CSV → Python → артефакты → Nikola → статический сайт**

## Связь с исследовательской работой

Структура демонстрационного проекта ориентирована
на будущую публикацию результатов экспериментов,
связанных с исследованием методов кэширования.

В текущей версии используются синтетические данные,
предназначенные для демонстрации возможностей pipeline.

В дальнейшем вместо демонстрационного набора могут быть
использованы результаты реальных экспериментов.
При этом основная архитектура конвейера сохраняется.
